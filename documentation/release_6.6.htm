New functionality

General

  • A new SPECT GPU projector is available for reconstruction of SPECT data including attenuation and collimator response. The implementation uses a rotating projector (i.e. filter, rotate the image and then project), as suggested by Jerold W. Wallis and Tom R. Miller, IEEE TMI 1997). The STIR implementation uses adjoint interpolation. See the User's Guide for details.
