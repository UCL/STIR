Summary for end users (also to be read by developers)

New functionality

General

  • Initial support for reading PETSIRD 0.9 list-mode data, the proposed standard for PET list-mode data from the Emission Tomography Standardization Initiative (ETSI). Some limitations include single layer, single module type geometry, no singles histogram, no dead-time. See also STIR2PETSIRD for using STIR to write PETSIRD data.
    PR #1604.
  • Support for even number of TOF bins.
    PR #1604.

Build system

  • CMake: fix problem compiling STIR registries where fmt.h is not found.
    PR #1604.
