Summary for end users (also to be read by developers)

Bug fixes

  • Fix incompatibility problem with ROOT 6.38 or later. Previous versions of STIR either crashed or threw an error Entry is null.
    PR #1741.

New functionality

General

  • Initial support for reading PETSIRD 0.9 list-mode data, the proposed standard for PET list-mode data from the Emission Tomography Standardization Initiative (ETSI). Some limitations include single layer, single module type geometry, no singles histogram, no dead-time. See also STIR2PETSIRD for using STIR to write PETSIRD data.
    PR #1604.
  • Support for even number of TOF bins.
    PR #1604.

Reconstruction

  • New PreconditionedGradientReconstruction (registered name Preconditioned Gradient), a composable reconstruction that implements the preconditioned update x <- [x + alpha_k P(x) g]_+ and delegates its two ingredients to registered families, selected at run time with the .par keys gradient estimator type and preconditioner type:
    • GeneralisedGradientEstimator: Full Gradient, Ordered Subsets, SVRG, SAGA;
    • GeneralisedPreconditioner: Identity, EM (with the full or the per-subset sensitivity), Hessian Diagonal (the Hessian diagonal of the prior), SPS (the separable paraboloidal surrogate curvature).
    Multiplicative algorithms are the special case P = diag(x/sensitivity): with a unit step, Full Gradient + EM is MLEM and Ordered Subsets + EM (per-subset sensitivity) is OSEM, while Ordered Subsets + SPS with a relaxed step is OSSPS. Compositions that make no sense are refused by set_up() with a message naming the offending axis: an estimator of the full gradient cannot be combined with a per-subset preconditioner, and Hessian Diagonal and SPS each require a prior exposing the curvature they use (respectively compute_Hessian_diagonal(), i.e. a Gibbs prior, and a parabolic surrogate, i.e. Quadratic or Logcosh). See examples/samples/PreconditionedGradient_*.par.
  • New PreconditionedSVRGReconstruction (registered name PSV), a locked preset of the above: preconditioned SVRG with the Hessian diagonal of the Relative Difference Prior, as submitted to the PETRIC2 challenge. See examples/samples/PSV_RDP.par.
  • GeneralisedPrior gained provides_Hessian_diagonal(), a capability query that lets a caller find out whether a prior implements compute_Hessian_diagonal() before asking for it (it returns false by default, and true for the Gibbs priors). This turns what used to be a run-time error deep inside an iteration into a diagnosis at set-up.

Changed functionality

  • STIR now requires SWIG 4.2 or later to build the Python interface. Recent SWIG versions (verified with 4.5) no longer generate the module-level aliases that SWIG 4.0 generated for static member functions. Python code using the flattened form stir.ClassName_method(...) — for instance stir.Verbosity_set(0), stir.ProjData_read_from_file(...) or stir.Scanner_get_scanner_from_name(...) — fails with an AttributeError and has to call the static method on the class instead, e.g. stir.Verbosity.set(0). The class form works with old and new SWIG versions.

Build system

  • CMake: fix problem compiling STIR registries where fmt.h is not found.
    PR #1604.
  • SWIG: update SWIG files for compatibility with SWIG 4.5
    PR #1743.

What is new for developers (aside from what should be obvious from the above):

Changed functionality

  • Allow local running of a GitHub Action via act (see local-CI.md.

New Deprecations and renames

    Scanner::get_detector_map_sptr() is now deprecated. Use get_detector_coordinate_map() instead (or get_detector_coordinate_map_sptr if you need to).
    PR #1731.

Test changes

All new features and most code changes were accompanied by new tests.

  • ProjDataInfo*::get_m() etc now have explicit consistency checks.
    PR #1731.
  • New test_PreconditionedGradient for the composable reconstruction: the compositions that set_up() has to refuse, MLEM and OSEM composed with the engine against OSMAPOSL, exact identities of the SVRG and SAGA gradient estimators, and the PSV preset against the composition it stands for.
