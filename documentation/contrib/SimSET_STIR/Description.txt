Description of the work

The intention of this work was to be able to run the SimSET Monte Carlo package 
on images written using STIR routines, and to convert the SimSET output 
to a file format which is readable by STIR.

## Reading SimSET history files as listmode Input

Contributor: 
    * Nikos Efthimiou (University of Hull, UK)
