# Pointers to installation instructions

The easiest option is to use Conda, as STIR is on conda-forge, see
[our wiki page](https://github.com/UCL/STIR/wiki/Installing-STIR-with-conda).

You could also use the [SyneRBI VM](https://github.com/UCL/STIR/wiki/Getting-STIR-on-a-Virtual-Machine),
or its [docker image](https://github.com/SyneRBI/SIRF-SuperBuild/tree/master/docker#readme)
(currently this only has the STIR Python interface, but not the STIR executables).

You can also build STIR yourself using CMake.
Please consult the STIR User's Guide (available in the
documentation and on the web-site) and the STIR Wiki.
